Mobile First

O CSS base foi escrito pensando primeiro em telas pequenas. As regras dentro das Media Queries ampliam e reorganizam o layout quando a largura disponível aumenta.

display: flex

Transforma um elemento em um contêiner Flexbox, permitindo organizar seus elementos filhos em linha ou coluna.

flex-direction

Define a direção dos itens do Flexbox. No mobile usamos coluna; nas telas maiores, algumas estruturas passam para linha.

flex-wrap

Permite que os itens de uma linha sejam distribuídos em novas linhas quando não há espaço suficiente.

gap

Cria espaçamento uniforme entre itens de um contêiner Flexbox, evitando depender de margens individuais.

Media Query

Com @media (min-width: ...), regras adicionais são aplicadas somente a partir de determinada largura de tela.

order

Permite alterar a ordem visual de itens Flexbox. Foi usado na página de venda para adaptar a prioridade visual entre tamanhos de tela.

Breakpoints utilizados

  • 700px: primeira mudança para layouts maiores, principalmente menu e colunas.
  • 1050px: segunda mudança para ampliar a composição da landing page e apresentar a sidebar de forma mais destacada.

Regras da atividade atendidas

  • Viewport em todas as páginas.
  • Menu Flexbox vertical no mobile e horizontal em telas maiores.
  • Layouts em colunas nas páginas Minha cidade e Meu sonho.
  • Landing page de infoproduto com Flexbox e sidebar.
  • Conteúdo específico para mobile e desktop na landing page.
  • CSS externo e ausência de regras de prioridade forçada.
